## Problem

Museum objects were catalogued on handwritten cards, which is slow to create and hard to search.

## What I built

A four-person team, Software Mahia, built HiFadithi through the KamiLimu innovation programme. I built the 3D model pipeline and the backend.

## How it works

A researcher photographs an object from a phone browser. The system builds a textured 3D model in the background using Meshy AI. The researcher checks the model against the real object using measured dimensions, then adds the object's story and a recorded narration. Records are versioned, role-based and searchable.

## Result

HiFadithi is in pilot, intended for museums across Kenya.
